🌐 Terraform Multi-Cloud VPN Deployment Guide  |  AWS / Azure / GCP  |  v1.0

Who is this for? Any engineer on Day 1 — no prior Terraform experience needed. Follow each step in order.

🖥️ Part 1 — Install Required Tools

1Install Terraform
  1. Go to developer.hashicorp.com/terraform/downloads
  2. Download Windows AMD64 zip
  3. Extract terraform.exe to C:\terraform\
  4. Add C:\terraform to System PATH (Search → "Environment Variables" → Edit Path)
  5. Open a new terminal and verify:
terraform version
Expected: Terraform v1.x.x
2Install AWS CLI
  1. Go to aws.amazon.com/cli
  2. Download and run the Windows MSI installer
  3. Verify:
aws --version
Expected: aws-cli/2.x.x
3Install Git
  1. Go to git-scm.com/download/win
  2. Download and run the installer (keep all defaults)
  3. Open a new terminal and verify:
git --version
Expected: git version 2.x.x

🔑 Part 2 — Configure AWS Access

4Configure AWS credentials 
aws configure

Enter when prompted:

AWS Access Key ID:     AKIAIOSFODNN7EXAMPLE
AWS Secret Access Key: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

5Verify AWS access 
aws sts get-caller-identity
You should see your Account ID and IAM user ARN. If you do — you're logged in ✅

📥 Part 3 — Get the Code

6Clone the repository 
git clone https://github.com/gsbarure/terraform-multicloud-vpn.git
cd terraform-multicloud-vpn

⚙️ Part 4 — Configure Your Deployment

7Go to the AWS environment folder 
cd envs\aws
8Create your tfvars file 
copy terraform.tfvars.example terraform.tfvars

Open terraform.tfvars in any text editor and fill in your values:

If you have an existing VPC:

use_existing_vpc    = true
on_prem_gateway_ip  = "203.0.113.10"       # Your router/firewall public IP
on_prem_cidr        = "192.168.1.0/24"     # Your on-prem network range
shared_key          = "MyVPNKey2026abc"    # Letters and numbers only
aws_vpc_id          = "vpc-xxxxxxxxxx"     # Your VPC ID
aws_route_table_ids = ["rtb-xxxxxxxx"]     # Your route table IDs

If you want a new VPC:

use_existing_vpc    = false
vpn_cidr            = "10.0.0.0/16"
on_prem_gateway_ip  = "203.0.113.10"
on_prem_cidr        = "192.168.1.0/24"
shared_key          = "MyVPNKey2026abc"
⚠️ shared_key rules: Use only letters and numbers. No @, !, # or special characters.

🚀 Part 5 — Deploy

9Initialize Terraform 
terraform init
Expected: Terraform has been successfully initialized!
10Preview changes (no resources created yet) 
terraform plan

Review the list of resources. You should see aws_vpn_gateway, aws_customer_gateway, aws_vpn_connection.

11Deploy 
terraform apply -auto-approve
⏳ This takes 5–10 minutes. The VPN connection takes time to provision in AWS. This is normal.

📄 Part 7 — Customer Configuration File

The file envs/aws/vpn-customer-config.txt is auto-generated after every apply.

It contains:

  • Tunnel 1 and Tunnel 2 settings
  • Pre-shared keys for both tunnels
  • IKE / IPSec parameters (encryption, lifetime, DH group)
  • Inside and outside IP addresses
  • Static routing instructions
📧 Send this file to your on-premises network team. They use it to configure their firewall or router.

✅ Part 8 — Verify in AWS Console

  1. Go to: AWS Console → VPC → Site-to-Site VPN Connections
  2. Find your VPN Connection ID from the output
  3. Status should show Available
  4. Click on it → Tunnel Details tab → tunnels show UP once on-prem is configured

🧹 Part 9 — Cleanup

To remove all resources when done:

terraform destroy -auto-approve
This deletes the VPN Gateway, Customer Gateway, VPN Connection, and routes. It does NOT delete your existing VPC.

🔐 Security Notes

  • Never commit terraform.tfvars — it is blocked by .gitignore
  • Rotate the shared_key regularly
  • Use IAM roles instead of access keys in production
  • Store secrets in AWS Secrets Manager for production workloads
